## External dataset

The evaluation used the official **test** partition of the Hugging Face dataset [`jmmrcp/phishing-IBM`](https://huggingface.co/datasets/jmmrcp/phishing-IBM), file `test-00000-of-00001.parquet`. The hosted dataset viewer lists 16,672 records across a 15,004-row train partition and a 1,668-row test partition, with a text field (`features`) and integer target (`target`). The test file SHA-256 is `894957417dd8b5d7cb8ad96b14fdb95aac268f4d6a64901394501d2a99f2eba0`. The dataset viewer examples show ordinary business email with target 0 and suspicious unsolicited offers with target 1; the external task mapping used here is **0 = legitimate/safe, 1 = phishing**. A 2026 cross-corpus study reports that 30.99% of this repository's full corpus matched its own Dataset A under a 200-character prefix rule. That is not an overlap estimate for this project's training data, but it shows public corpus reuse is possible ([study](https://www.mdpi.com/2079-9202/15/14/3051)).

Only the repository's official test partition was scored. Its train partition was not used to train or tune this model. The external rows were never added to the project training data. The source's feature is already preprocessed text; it is not a raw MIME or `.eml` archive. Target 1 also includes spam-like promotions/scams, so these results reflect the source's broad phishing label and are not a pure credential-phishing benchmark. The hosted README is empty and the dataset card does not clearly state a license; check the source terms before redistributing the files.

## Preprocessing and overlap control

- Raw official test rows: **1,668**; target counts: **{0: 801, 1: 867}**. Missing text/labels: 0; invalid labels: 0; empty text rows: 0.
- Labels were verified to be binary and mapped as 0=legitimate, 1=phishing. Exact duplicate analysis used case-folded alphanumeric word tokens, which removes superficial punctuation-spacing differences. Conflicting-label duplicate texts: 0; duplicate rows removed within the external test set: 1.
- Training comparisons used only rows marked `train` in `grouped_split_manifest.csv` (65,661 project training emails). Canonical exact matches to those rows: **25**, removed before scoring.
- Near-duplicate search used the same project similarity method on canonical word tokens: word-trigram Jaccard ≥0.90 with 32-bit CRC32 SimHash Hamming distance ≤3. This found **4** near-match links covering **4** external rows, which were excluded. Conflicting-label pairs in the similarity graph: 0.
- Retained external evaluation set: **1,638** rows, with labels `{0: 787, 1: 851}`. The saved vectorizer was loaded and used with `transform()` only; it was never refit. Predictions were generated by the selected saved Logistic Regression model.

This is a conservative overlap screen, not proof that all remaining messages have independent provenance. The external set contains old Enron-style threads and spam examples; shared source collections or lightly edited messages can remain below the chosen similarity threshold.

## Error analysis

### False positives

**False positives: 1**
- Phishing probability 81.49%: `gymnastics pictures`

The retained false positive is a two-word message (`gymnastics pictures`) with little context. Very short messages can be difficult to classify from content alone; review the source label and surrounding email context before using the model to quarantine messages automatically.

### False negatives

**False negatives: 4**
- Phishing probability 36.97%: `bi - weekly payment requests to unsubscribe email warrenc @ mortgagesaver . com with unsubscribe in the subject line`
- Phishing probability 42.43%: `what if you had . . asuncion fantastic success usually comes to those who are too busy to be looking for it - henry david thoreau ( 1817 - 1862 ) there are only two tragedies in life : one is not getting what one wants ; and the other is getting it . - oscar wilde ( 1854 - 1900 ) dont let it end like this . tell them i`
- Phishing probability 48.49%: `re [ 14 ] : ? ? ? ? shakespeare mortage rates or study ? would you like to pay the point is`
- Phishing probability 49.78%: `education grants available , apply now`

The retained false negatives include a mortgage/payment unsubscribe message, a quote-heavy message with a vague call to action, a short reply-like mortgage phrase, and a short grant offer. These lack overt credential theft language and several are very short; the broad target-1 label may include unsolicited spam/scams that do not fit a narrow phishing definition. The model sees normalized text only and cannot inspect sender authentication, URL reputation, or attachment contents.

## Limitations and recommendations

1. Treat this as one external-corpus check, not a production guarantee. The remaining **1,638** records are from a single historical corpus and may share source families with the project data despite exact and high-similarity filtering.
2. Confirm the source's `target=1` policy distinguishes phishing from general spam/scams. Relabel or report these categories separately if the deployment objective is credential theft or malicious-link phishing specifically.
3. Validate on a recent, organization-separated and human-adjudicated email corpus with original subject, headers, URLs, and attachment metadata. Keep sender/domain/thread grouping intact across datasets.
4. Inspect the false negatives and false positives, then measure calibration and operational thresholds on a separate validation set. Do not tune thresholds on this external test report.
